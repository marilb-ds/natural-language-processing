# Text Classification Lab

This lab applies vectorization techniques and logistic regression for sentiment classification using the NLTK movie reviews dataset.

## Steps
1. Create a vector representation of the data.
2. Optimize hyperparameters on the validation set.
3. Evaluate on the test set.
4. Print the 30 tokens with the highest absolute coefficient values.

## Libraries
- numpy
- nltk
- scikit-learn
- spaCy
